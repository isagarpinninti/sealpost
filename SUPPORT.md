# Getting help

- **Questions and how-tos:** start with [docs/GETTING_STARTED.md](docs/GETTING_STARTED.md) and the [docs index](docs/README.md).
- **Something is broken:** open a [bug report](https://github.com/isagarpinninti/sealpost/issues/new?template=bug_report.md) with the output of `sealpost doctor --json` (it contains no secrets).
- **Security problems:** do not open a public issue. Follow [SECURITY.md](SECURITY.md).
